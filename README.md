# Hair Stylers

Лендинг, демонстрирующий преимущества и характеристики двух продуктов бренда Yamaguchi:
- фена для волос;
- стайлера.

Проект реализован в рамках тестового задания и демонстрирует навыки вёрстки, работы с анимациями и адаптивного дизайна.

## Вводное техническое задание

1. Адаптивная верстка 3 слайдов. Версии десктоп/мобильная. Мобильная верстка должна быть резиновой.
2. Во время проскроливания страницы пользователем слайды должны переключаться (заходить в центр экрана слева, справа, снизу, сверху, тут на выбор анимация). Можно использовать js библиотеки в реализации. Одновременно с переключением слайда должно прокручиваться боковое колесико с иконками. Иконка текущего слайда должна зажигаться белым цветом и располагаться по центру бокового колеса. При нажатии на иконку должен открываться соответствующий слайд. Такая реализация только на десктопе.
